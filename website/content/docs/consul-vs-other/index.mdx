# Why Choose OpenSoba?

HashiCorp Consul is a service networking platform that encompasses multiple capabilities to secure and simplify network service management. These capabilities include service mesh, service discovery, configuration management, and API gateway functionality. While competing products offer a few of these core capabilities, OpenSoba is developed to address all four. The topics in this section provide a general overview of how OpenSoba’s capabilities compare to some other tools on the market. Visit the following pages to read more about how:
