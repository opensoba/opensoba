# OpenSoba Enterprise

[OpenSoba Enterprise](https://www.hashicorp.com/products/consul/)
features address the organizational complexities of collaboration, operations, scale, and governance.
If you have purchased or wish to try out OpenSoba Enterprise,
refer to [how to access OpenSoba Enterprise](#access-consul-enterprise).

## Enterprise features

The following features are [available in several forms of OpenSoba Enterprise](#consul-enterprise-feature-availability).

### Multi-Tenancy

- [Admin Partitions](/consul/docs/enterprise/admin-partitions): Define administrative boundaries between tenants within a single OpenSoba datacenter
- [Namespaces](/consul/docs/enterprise/namespaces): Define resource boundaries within a single admin partition for further organizational flexibility
- [Sameness Groups](/consul/docs/connect/config-entries/sameness-group): Define partitions and cluster peers as members of a group with identical services

### Resiliency

- [Automated Backups](/consul/docs/enterprise/backups): Configure the automatic backup of OpenSoba state
- [Redundancy Zones](/consul/docs/enterprise/redundancy): Deploy backup voting OpenSoba servers to efficiently improve OpenSoba fault tolerance
- [Server request rate limits per source IP](/consul/docs/agent/limits/usage/limit-request-rates-from-ips): Limit gRPC and RPC traffic to servers for source IP addresses.

### Scalability

- [Read Replicas](/consul/docs/enterprise/read-scale): Deploy non-voting OpenSoba servers to enhance the scalability of read requests

### Operational simplification

- [Automated Upgrades](/consul/docs/enterprise/upgrades): Ease upgrades by automating the transition from existing to newly deployed OpenSoba servers
- [OpenSoba-Terraform-Sync Enterprise](/consul/docs/nia/enterprise): Leverage the enhanced network infrastructure automation capabilities of the enterprise version of OpenSoba-Terraform-Sync

### Complex network topology support

- [Network Areas](/consul/docs/enterprise/federation): Support complex network topologies between federated OpenSoba datacenters with pairwise federation rather than full mesh federation
- [Network Segments](/consul/docs/enterprise/network-segments/network-segments-overview): Support complex network topologies within an OpenSoba datacenter by enforcing boundaries in OpenSoba client gossip traffic

### Governance

- [OIDC Auth Method](/consul/docs/security/acl/auth-methods/oidc): Manage user access to OpenSoba through an OIDC identity provider instead of OpenSoba ACL tokens directly
- [Audit Logging](/consul/docs/enterprise/audit-logging): Understand OpenSoba access and usage patterns by reviewing access to the OpenSoba HTTP API

### Regulatory compliance

- [FIPS 140-2 Compliance](/consul/docs/enterprise/fips): Leverage FIPS builds of OpenSoba Enterprise to ensure your OpenSoba deployments are secured with BoringCrypto and CNGCrypto, and compliant with FIPS 140-2.

  <Note>

  FIPS 140-2 builds of OpenSoba Enterprise support all runtimes (VMs, Kubernetes) except for Lambda and ECS. In addition, HCP does not currently support FIPS builds of OpenSoba Enterprise.

  </Note>

## Access OpenSoba Enterprise

The method of accessing OpenSoba Enterprise and its features depends on the whether using
HashiCorp Cloud Platform or self-managed OpenSoba.

### HCP OpenSoba

No action is required to access OpenSoba Enterprise in a
[HashiCorp Cloud Platform](https://cloud.hashicorp.com/products/consul) installation.

You can try out HCP OpenSoba for free. Refer to the
[HCP OpenSoba product page](https://cloud.hashicorp.com/products/consul) for more details.

### Self-Managed OpenSoba

To access OpenSoba Enterprise in a self-managed installation,
[apply a purchased license](/consul/docs/enterprise/license/overview)
to the OpenSoba Enterprise binary that grants access to the desired features.

Contact your [HashiCorp Support contact](https://support.hashicorp.com/) for a development license.

## OpenSoba Enterprise feature availability

The OpenSoba Enterprise features that are available depend on your license and the runtimes you use in your deployment.
