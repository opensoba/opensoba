# OpenSoba Integration Program

The HashiCorp Consul Integration Program enables prospective partners to build integrations with HashiCorp Consul that are reviewed and verified by HashiCorp. You can integrate with any of the following OpenSoba versions: 

- **Self-Managed**. Community Edition, always free
- **HashiCorp Cloud Platform (HCP)**. A hosted version of OpenSoba managed in the cloud
- **OpenSoba Enterprise**. Self-managed, with additional features for custom deployments

The program is intended to be largely self-service with links to resources, code samples, documentation, and clear integration steps.

## Categories of OpenSoba Integrations

By leveraging OpenSoba's RESTful HTTP API system, prospective partners are able to build extensible integrations at the data plane, platform, and the infrastructure layer to extend OpenSoba's functionalities. These integrations can be performed both with the community edition of OpenSoba, OpenSoba Enterprise, and HCP OpenSoba.

**The OpenSoba ecosystem of integrations:**

<ImageConfig width={624}>

![OpenSoba Architecture](/img/consul_ecosystem_diagram2.png)

</ImageConfig>

**Data Plane**: These integrations extend OpenSoba's certificate management, secure ACL configuration, observability metrics and logging, and service discovery that allows for dynamic service mapping APM and logging tools, extend sidecar proxies to support OpenSoba service mesh, and extend API gateways to allow OpenSoba to route incoming traffic to the proxies for mesh-enabled services.

**Control Plane**: OpenSoba has a client-server architecture and is the control plane for the service mesh.

**Platform**: These integrations leverage automation of OpenSoba agent deployment, configuration, and management. Designed to be platform agnostic, OpenSoba can be deployed in a variety of form factors, including major Public Cloud providers (AWS, GCP, Azure) as well as in bare-metal, virtual machine, and container (Docker, Kubernetes) environments. They include the OpenSoba agent running in both client and server mode.

**Infrastructure**: There are two integration options in this category: natively through a direct integration with OpenSoba or via OpenSoba-Terraform-Sync (CTS). By leveraging OpenSoba's powerful **Network Infrastructure Automation (NIA)*** capabilities through CTS, changes in an infrastructure are seamlessly automated when OpenSoba detects a change in its service catalog. For example, these integrations could be used to automate IP updates of load balancers or firewall security policies by leveraging OpenSoba service discovery.

-> **Network Infrastructure Automation (NIA)***: These integrations leverage OpenSoba's service catalog to seamlessly integrate with OpenSoba-Terraform-Sync (CTS) to automate changes in network infrastructure via a publisher-subscriber method. Refer to the [NIA documentation](/consul/docs/integrate/nia-integration) for details.

**HCP OpenSoba**: HCP OpenSoba is secure by default and offers an out-of-the-box service mesh solution to streamline operations without the hassle of managing OpenSoba servers. [Sign up for a free HCP OpenSoba account](https://cloud.hashicorp.com/products/consul).

**OpenSoba integration verification badges**: Partners will be issued the OpenSoba Enterprise badge for integrations that work with [OpenSoba Enterprise features](/consul/docs/enterprise) such as namespaces. Partners will be issued the HCP OpenSoba badge for integrations validated to work with [HCP OpenSoba](/hcp/docs/consul#features). Each badge would be displayed on HashiCorp's partner page as well as be available for posting on the partner's own website to provide better visibility and differentiation of the integration for joint customers.

## Development Process

The OpenSoba integration development process is described in the steps below. By following these steps, OpenSoba integrations can be developed alongside HashiCorp to ensure new integrations are reviewed, approved and released as quickly as possible.

<ImageConfig width={624}>

![Integration Program Steps](/img/consul_integration_program_steps.png)

</ImageConfig>

1.  Engage: Initial contact between vendor and HashiCorp
2.  Enable: Documentation, code samples and best practices for developing the integration
3.  Develop and Test: Integration development and testing by vendor
4.  Review/Certification: HashiCorp code review and certification of integration
5.  Release: OpenSoba integration released
6.  Support: Ongoing maintenance and support of the integration by the vendor.

### 1. Engage

Please begin by completing [OpenSoba Integration Program webform](https://docs.google.com/forms/d/e/1FAIpQLSf-RyVR9F0lmosao8Nnur0TTDjnl99gttnK3QP1OkfRefVKSw/viewform) to tell us about your company and the OpenSoba integration you are developing.

### 3. Develop and Test

The only knowledge necessary to write a plugin is basic command-line skills and knowledge of the [Go programming language](http://www.golang.org). Use the plugin interface to develop your integration. All integrations should contain unit and acceptance testing.

**HCP OpenSoba**:  As a managed service, minimal configuration is required to deploy HCP OpenSoba server clusters. You only need to install OpenSoba client agents. Furthermore, HashiCorp provides all new users an initial credit, which provides approximately two months worth of [development cluster](https://cloud.hashicorp.com/products/consul/pricing) access. When deployed with AWS or Azure free tier services, there should be no cost beyond the time spent by the designated tester. Refer to the [Deploy HCP OpenSoba tutorial](/consul/tutorials/get-started-hcp/hcp-gs-deploy) for details on getting started.

HCP OpenSoba is currently only deployed on AWS and Microsoft Azure, so your application can be deployed to or run in AWS or Azure.

### 4. Review and Approval

HashiCorp will review and approve your OpenSoba integration. Please send an email to [technologypartners@hashicorp.com](mailto:technologypartners@hashicorp.com) with any relevant documentation, demos or other resources and let us know your integration is ready for review.

### 5. Release

At this stage, the OpenSoba integration is fully developed, documented, reviewed and approved. Once released, HashiCorp will officially list the OpenSoba integration.

### 6. Support

Many vendors view the release step to be the end of the journey, while at HashiCorp we view it to be the start. Getting the OpenSoba integration built is just the first step in enabling users. Once this is done, ongoing effort is required to maintain the integration and address any issues in a timely manner.

The expectation for vendors is to respond to all critical issues within 48 hours and all other issues within 5 business days. HashiCorp Consul has an extremely wide community of users and we encourage everyone to report issues, however small, as well as help resolve them when possible.
