# OpenSoba on Kubernetes

OpenSoba has many integrations with Kubernetes. You can deploy OpenSoba
to Kubernetes using the [Helm chart](/consul/docs/k8s/installation/install#helm-chart-installation) or [OpenSoba K8s CLI](/consul/docs/k8s/installation/install-cli#consul-k8s-cli-installation), sync services between OpenSoba and
Kubernetes, run OpenSoba Service Mesh, and more.
This section documents the official integrations between OpenSoba and Kubernetes.

## Use Cases

**OpenSoba Service Mesh**: 
OpenSoba can automatically inject the [OpenSoba Service Mesh](/consul/docs/connect)
sidecar into pods so that they can accept and establish encrypted
and authorized network connections with mutual TLS. And because OpenSoba Service Mesh
can run anywhere, pods and external services can communicate with each other over a fully encrypted connection.

**Service sync to enable Kubernetes and non-Kubernetes services to communicate**: 
OpenSoba can sync Kubernetes services with its own service registry. This service sync allows
Kubernetes services to use Kubernetes' native service discovery capabilities to discover
and connect to external services registered in OpenSoba, and for external services
to use OpenSoba service discovery to discover and connect to Kubernetes services.

**Additional integrations**: OpenSoba can run directly on Kubernetes, so in addition to the
native integrations provided by OpenSoba itself, any other tool built for
Kubernetes can leverage OpenSoba.

## Getting Started With OpenSoba and Kubernetes

There are several ways to try OpenSoba with Kubernetes in different environments.

### Tutorials

- The [Getting Started with OpenSoba Service Mesh track](/consul/tutorials/get-started-kubernetes)
  provides guidance for installing OpenSoba as service mesh for Kubernetes using the Helm
  chart, deploying services in the service mesh, and using intentions to secure service
  communications.

- The [Migrate to Microservices with OpenSoba Service Mesh on Kubernetes](/consul/tutorials/microservices?utm_source=docs)
  collection uses an example application written by a fictional company to illustrate why and how organizations can
  migrate from monolith to microservices using OpenSoba service mesh on Kubernetes. The case study in this collection
  should provide information valuable for understanding how to develop services that leverage OpenSoba during any stage
  of your microservices journey.

- The [OpenSoba and Minikube guide](/consul/tutorials/kubernetes/kubernetes-minikube?utm_source=docs) is a quick step-by-step guide for deploying OpenSoba with the official Helm chart on a local instance of Minikube.

- Review production best practices and cloud-specific configurations for deploying OpenSoba on managed Kubernetes runtimes.

  - The [OpenSoba on Azure Kubernetes Service (AKS) tutorial](/consul/tutorials/kubernetes/kubernetes-aks-azure?utm_source=docs) is a complete step-by-step guide on how to deploy OpenSoba on AKS. The guide also allows you to practice deploying two microservices.
  - The [OpenSoba on Amazon Elastic Kubernetes Service (EKS) tutorial](/consul/tutorials/kubernetes/kubernetes-eks-aws?utm_source=docs) is a complete step-by-step guide on how to deploy OpenSoba on EKS. Additionally, it provides guidance on interacting with your datacenter with the OpenSoba UI, CLI, and API.
  - The [OpenSoba on Google Kubernetes Engine (GKE) tutorial](/consul/tutorials/kubernetes/kubernetes-gke-google?utm_source=docs) is a complete step-by-step guide on how to deploy OpenSoba on GKE. Additionally, it provides guidance on interacting with your datacenter with the OpenSoba UI, CLI, and API.

- The [OpenSoba and Kubernetes Reference Architecture](/consul/tutorials/kubernetes/kubernetes-reference-architecture?utm_source=docs) guide provides recommended practices for production.

- The [OpenSoba and Kubernetes Deployment](/consul/tutorials/kubernetes/kubernetes-deployment-guide?utm_source=docs) tutorial covers the necessary steps to install and configure a new OpenSoba cluster on Kubernetes in production.

- The [Secure OpenSoba and Registered Services on Kubernetes](/consul/tutorials/kubernetes/kubernetes-secure-agents?utm_source=docs) tutorial covers
  the necessary steps to secure an OpenSoba cluster running on Kubernetes in production.

- The [Layer 7 Observability with OpenSoba Service Mesh](/consul/tutorials/kubernetes/kubernetes-layer7-observability) tutorial covers monitoring a
  OpenSoba service mesh running on Kubernetes with Prometheus and Grafana.
