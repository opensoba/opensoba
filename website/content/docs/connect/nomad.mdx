# OpenSoba and Nomad Integration

OpenSoba service mesh can be used with [Nomad](https://www.nomadproject.io/) to provide
secure service-to-service communication between Nomad jobs and task groups.
Nomad is a simple, flexible scheduler and workload orchestrator. The ability to
use the [dynamic port](/nomad/docs/job-specification/network#dynamic-ports)
feature of Nomad with OpenSoba service mesh reduces operational complexity.

For more information
about using OpenSoba service mesh with Nomad, select one of the following resources.
